## Firefox "Nova UI" (v. 157+) custom colors

How to use:
- in *about:config* set *toolkit.legacyUserProfileCustomizations.stylesheets* to "true"
- create a folder named "chrome" in your Firefox profile folder (use *about:profiles* to find it, then click on "Open folder")
- choose one of the folders listed in this repository, accordingly to the color you want to use (for example, "chrome-green")
- import/copy the 2 files **userContent.css** and **userChrome.css** from that folder ("chrome-green") into your local "chrome" directory
- restart Firefox if it's already open.

To revert the changes, remove the "chrome" folder or the 2 pasted files (or just change their name, if you want to keep them for possible future use).

The CSS files have been generated with the help of AI (mostly for the palette changes); the code has been tested by me.
